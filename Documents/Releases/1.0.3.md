Luros 1.0.3 unlocks a locked device for the agent, sends videos from the composer, and lets you tell the chat how to work.

- **A chat that needs the screen while the device is locked can carry on.** Permission Mode has a second switch, **Let the Agent Unlock the Device**, shown while Ask Before Using the Screen is off: turning it on saves this device's passcode once — Luros locks the screen and tries it a single time to prove it works — and the agent then presses unlock itself, reaching the Home Screen to do what you asked. A device with no passcode needs none to turn it on. With Ask Before Using the Screen on, the switch is hidden, because every use of the screen is approved anyway; the passcode stays in the device's keychain, and the agent never sees it. What the agent reads now says when it may unlock and to ask you when it may not.
- **The composer's Photo tile is Media.** A video could not be sent at all before; now it goes in whole, named in the project, and the message tells the agent the file's name and where it sits, so it can work from the file. Pictures still reach the model as pictures.
- **A chat's More menu opens Custom Instructions**: what the agent follows in every chat, what it follows in this project, and, read-only, the project's `AGENTS.md` or `CLAUDE.md` — the same file the agent reads — so you can see what it is working to. An edit arrives with your next message, and instructions changed in another window are reported instead of being overwritten.
- **Settings ▸ Skills can find skills in a public GitHub repository.** Paste a link to a repository, a folder in one, or a `SKILL.md`, preview what it found with each one's description, and import the ones you pick; a name already taken asks before its files are replaced, and anything that cannot be imported says why.
- **A project's Distribute Project page publishes the packages a build made as a GitHub Release.** It names the tag and the commit it must be on, refuses a tag that is not on GitHub yet, uploads one version of a package at a time, and reports what it published. An agent publishes a release only with your approval, on a card that names the repository, the tag and the packages.
- **Settings ▸ Models ▸ a model says which Context Window your chats are read against**, and **Max Output Tokens**; both can be set there in place of what the catalog reports, and left empty to keep the automatic figure.
- **A reply that would not stop no longer spins forever**: Luros ends it, says the reply was ended, and your next message picks the chat up.

Requires iOS or iPadOS 16.0 or later and an A12 chip or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
