Luros 1.0.1 installs its own packages, measures what it keeps on the device, and fixes the ignore button that wrote nothing.

- **A package installs without another package installed first.** Luros carries its own installer now, so a device that never had one still takes a `.deb`, and another app's installer can no longer leave Luros's waiting for ever.
- **A removal leaves no icon behind.** The app is unregistered before its files go, and the answer names the transaction the installer ran rather than the task.
- **Settings ▸ Storage** measures each area Luros keeps on the device and clears the ones no model indexes, refusing while a build or an environment task is running and leaving anything written in the last hour alone.
- **The Debug build's download is the one package Luros installs**, not the extension packages that happened to be built beside it.
- **A shared document opens in the conversation you are in**, and a large attachment streams in instead of being read whole.
- **On iOS 17 the conversation scrolls under the top bar** instead of vanishing into the black or white band iOS 17.3 drew there. Git and New Conversation moved into the conversation's own menu, and Generate with AI writes the commit message from the staged diff in the conversation's own model.
- **Chat themes and bubble colours are yours to set**, a saved image stays selectable, and an API-key model saves without being probed first.
- **Settings ▸ Environment ▸ Third-Party Tools** names ldid, git and python3, and says what each one is for.
- **A delegated conversation reaches the host only through the capabilities its brief declares**, and what a step lacked is recorded for the conversation that opened it.
- **Ignore on an untracked file now writes the line it promises.** A leading slash was refused as an absolute path, so nothing was added while the page said it had been.
- **A thinking model on a hand-entered endpoint answers.** Its system prompt went under OpenAI's newer `developer` role, which Qwen's DashScope refuses outright ("developer is not one of ['system', 'assistant', 'user', 'tool', 'function']"); it goes as `system` now.

Requires iOS or iPadOS 16.0 or later and an A12 chip or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
