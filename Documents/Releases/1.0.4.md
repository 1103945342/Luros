Luros 1.0.4 says what each provider has left before you pick a model, and lets one provider hold several accounts.

- **The composer no longer carries a quota figure; the model picker does.** Every endpoint in the model sheet now has a usage icon at the right of its host: tap it for that account's quota — a balance in money for the providers that bill that way, or the 5-hour, weekly and per-model windows for the ones that limit that way, with what is left and when it resets. The sheet asks the provider afresh each time it opens (showing the last answer first, so it never waits), refreshes from the top right or by pulling down, and a provider that cannot be asked says **Unable to query usage** instead of a breaker state — the API is not broken because its quota endpoint is.
- **Every provider can be signed in to more than one account.** Before, only an additional OpenAI-compatible endpoint could be added; now any provider takes a second, third … account, each with its own key or sign-in, its own models, its own quota and its own sign-out — open an account's menu in Model Providers and choose **Add Account**. A conversation remembers which account it used, so two logins of one provider are two choices in the picker.
- **Settings ▸ Model Providers ▸ Models fetches the provider's own list when it opens**, with **Refresh Models** beside Save and a spinner while it runs. A subscription account is asked too, which it never was; a provider that cannot answer leaves the list the account already knows, and says the fetch failed rather than emptying the page.
- **A second account no longer crashes the app.** The provider list gave two accounts of one provider the same row identity, which UIKit refuses; each account is its own row now.
- **Quota is kept without the secrets.** The cache holds a pool id and the figures, never a key or a response body; a provider that keeps failing is left alone for a day rather than retried on every look.
- **Model figures refreshed** from models.dev for the models it names.

Requires iOS or iPadOS 16.0 or later and an A12 chip or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
